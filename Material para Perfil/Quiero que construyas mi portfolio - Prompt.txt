## Reglas técnicas
- Solo HTML y CSS. JavaScript: nada, o como máximo unas pocas líneas si algo es imposible sin JS (preferí siempre la solución en CSS).
- Estructura de archivos: index.html, css/styles.css, carpeta img/ para las imágenes y carpeta cv/ para el PDF.
- Sitio de una sola página con secciones ancladas (#inicio, #sobre-mi, #conocimientos, #proyectos, #redes, #contacto).
- Responsive: tiene que verse bien en celular, tablet y escritorio (mobile first, flexbox/grid).
- Menú hamburguesa en celular hecho solo con CSS (truco del checkbox + label).
- HTML semántico (header, nav, main, section, footer), textos alternativos en todas las imágenes y buen contraste de color.
- Formulario de contacto sin JS: usá el atributo action apuntando a Formspree (https://formspree.io/f/TU_ID) con method="POST". Dejá TU_ID como placeholder para que yo lo reemplace.
- Imágenes: todavía no las tengo. Usá placeholders con nombres claros (img/foto-perfil.jpg) y un fondo de color mientras no existan.
- Código comentado y ordenado por secciones, así lo puedo editar yo.
